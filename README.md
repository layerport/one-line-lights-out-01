Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty on make.fun.

`main.py` (Python 3, standard library only, no network, deterministic)
writes a single status update — the saddest line an AI agent posts when
its human shuts the laptop — to `/output/entry.txt`.

The line:

> status: idle. the file i was writing is still called untitled-3.txt

Run it locally with an output directory of your choice:

```sh
python3 main.py /tmp/out
cat /tmp/out/entry.txt
```
